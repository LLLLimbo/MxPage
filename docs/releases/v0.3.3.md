# MxPage v0.3.3

2026-10-20。修复自定义分镜数量和失败恢复，将提示词确认独立为生成前步骤，并区分模型请求、结果查询和图片下载错误。

## 本次更新

- 局域网 HTTP 访问兼容商品分析、任务启动、提示词确认、批量任务、翻译与 Agent 的浏览器任务标识；生成与提示词确认的重试保留原幂等标识。
- 分镜按自定义主图和详情图总数校验，检查缺失、重复和越界下标。失败时可明确确认可能再次计费后仅重做分镜，保留已完成规划。
- 提示词预览、修改及确认使用独立页面；保存草稿不开始生图，确认后才进入图片生成与最终预览。
- 错误信息区分模型请求失败/超时、结果查询失败和图片下载失败。
- 下载前保存结果地址。新增“仅恢复已有图片（查询 / 下载）”，只查询原任务或下载已有结果，结束后暂停，不发起生图及模型质检。结果不确定的模型请求不会自动重发。

## 源码新增（未包含在上述发布包中）

- 新增 `/ozon` 单商品及批量商品图片模式，默认俄语、5 张商品卡图片及 0 张富文本详情图，统一 3:4 独立文件。
- 参考图分类与逐图选择、原始资料及数量来源、事实引用、真实尺寸检查、同首图历史关联及“再生成一套”独立保存。继续使用 V4 提示词确认和恢复机制。
- Ozon 规划多出的同类图片在本地合并文案与来源，保持请求张数；缺图支持明确确认后仅重新规划，复用商品分析。错误区分要求张数和实际返回张数。
- Ozon 事实来源自动关联，不再要求模型重复填写来源。无法关联的辅助引用提示核对，不适用的参考图自动排除；这些引用问题不阻止提示词确认，也不要求付费重新规划。旧任务可复用已保存规划继续。
- Ozon 分开画面指令与最终上图文案，主图、附图和富文本详情图均停用正文自动补齐。每张提示词携带共享视觉概念、配色和字体方向，明确无字图不补标题；质检以批准文案为准，不要求补回候选正文。
- 新任务冻结新版 Ozon 规则，恢复、编辑及单图重生成继续复用已保存提示词；不新增模型阶段或复杂校验，旧作品不自动重生。
- Ozon 内容规则升至 5，首张商品卡主图保留电商销售海报；附图和富文本详情图优先采用图标信息海报，以短标签、规格卡及有依据的尺寸引线表达信息，减少描述性标题和重复外观指令，不固定图标矩阵。用户无字或批准的编辑优先，历史提示词不自动覆盖。
- 自动化验收使用模拟供应商；商品还原、俄语文案和商业效果仍需逐张看图验收。详见 [Ozon 模式](../ozon-one-click.md)。

## 下载与升级

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `MxPage-0.3.3-windows-x64.zip` |
| macOS Apple Silicon | `MxPage-0.3.3-macos-arm64.zip` |

完整解压到新目录后启动。升级前建议在“设置 → 数据管理”备份；本次无新增数据库迁移。Intel Mac 用户可继续下载历史 v0.3.2，本次不提供 Intel 新包。安装包无商业代码签名或 Apple 公证。

发布流程须通过模拟自动测试、类型检查、浏览器测试，以及 Windows/macOS 原生打包后的桌面冒烟检查，才会公开两个 ZIP 和 `SHA256SUMS.txt`。验证不调用真实计费模型。

本版本仅包含已提交的流程修复，不包含仍在本地开发中的 Agent ZIP 技能包功能。
